# PAGE-063 — Veille

La Veille regroupe les sources en six catégories : Pokémon et disponibilité, Combat, Événements, Assets, Données et fournisseurs, Technique. Son accueil affiche les totaux, changements, erreurs actives et accès directs aux quatre contrôles Pokémon.

Les contrôles ETag, Last-Modified, commit GitHub et HTTP restent distincts des comparaisons métier. Une source joignable n'est pas nécessairement un dataset conforme.
